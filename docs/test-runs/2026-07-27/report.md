Single-claim `claimedByMixBatchId` no longer set on a plan-driven start.
  - Force-close of a plan-driven mixer restores that plan item to `Reserved` (mix stays Quarantined).
- `selftest.py` — updated to save a plan before each mixer start (models the WPF save via `hh.sim.world.save_mix_plan`), added a **mixer plan gate** section (mixer_plan_required, plan surfaces in readyCollections as MixingPlanned + reserved mixer is Reserved/scanAllowed in equipment[], mixer_not_in_plan).
